# REFMAP map chips

Source: https://refmap-l.blog.jp/archives/8655709.html

REFMAP states that these images may be used free of charge as game-development
materials without contacting the author. Processed images may be distributed;
redistribution of the original, unprocessed image data is prohibited. Copyright
remains with REFMAP. Check the source page again before publishing a release.

The game references the original atlas sheets and selects regions at runtime.
